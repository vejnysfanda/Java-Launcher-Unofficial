# Java Launcher Unofficial

An unofficial Minecraft: Java Edition launcher for iOS, based on PojavLauncher and Amethyst, maintained by Dualboot Gaming and upgraded with the help of CheatGPT (ChatGPT).

## Development status

- 1.0.1: Minecraft 26.2 with Fabric launched successfully on iPhone 13 using JIT via StikDebug.
- 1.0.2: development version; build and device testing pending.
- Bundle ID: `com.dualboot-gaming.mcjavalauncher`.

## Roadmap

- Import the modified source code and preserve upstream license notices.
- Configure GitHub Actions for macOS IPA builds.
- Preserve StikDebug integration.
- Investigate experimental No-JIT execution (not currently supported).
- Improve crash diagnostics and mod management.
